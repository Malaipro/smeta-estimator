# Smeta Estimator

Проект внутренней программы для предварительного расчёта стоимости строительства домов и выгрузки результата в Excel.

## Текущая стадия

Реализованы расчётное ядро свайно-ростверкового фундамента и закрытый
Telegram-демо-бот. Бот принимает параметры от сметчика, рассчитывает объёмы и
возвращает Excel. Для проверки схемы подключён временный каталог тестовых
цен из таблиц пользователя. Их дата, регион и актуальность не подтверждены.
Программа показывает частичный итог только по строкам, где известны и объём, и цена.

Подтверждённые границы первой версии:

- пользователь — сметчик;
- результат — предварительная, а не детальная рабочая смета;
- один или два этажа;
- простая геометрия дома;
- кирпич и Porotherm;
- готовые комплектации и ручной выбор разделов;
- расчёт до предчистовой отделки;
- выгрузка в Excel;
- будущая возможность предзаполнения параметров по плану или изображению.

## Расчётное ядро фундамента

Первая программная часть проекта находится в `src/smeta_estimator/foundation`.
Она рассчитывает геометрию свайно-ростверкового фундамента и формирует строки
предварительной сметы без Telegram, сервера и внешней базы данных. Временные цены и
демо-количества изолированы в `src/smeta_estimator/demo` и могут быть заменены без
изменения геометрического ядра.

Запуск тестов:

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## Telegram-демо

Бот поддерживает команды `/start`, `/new`, `/cancel` и `/help`, а также кнопки
для нового расчёта, навигации, выбора формы дома, этажности, материала стен,
условия по грунту и стандартных либо ручных параметров фундамента. По умолчанию
бот открыт всем пользователям. Если указать `ALLOWED_TELEGRAM_IDS`, доступ будет
ограничен перечисленными Telegram ID. История расчётов и исходные сообщения не
сохраняются.

Площадь, этажность, материал стен и условие по грунту экспортируются в Excel как
контекст объекта, но не меняют формулы до появления подтверждённых расчётных
правил. Для прямоугольного дома площадь и наружный периметр вычисляются из длины
и ширины.

Переменные окружения:

```text
TELEGRAM_BOT_TOKEN=<токен BotFather>
ALLOWED_TELEGRAM_IDS=<необязательно: один или несколько Telegram ID через запятую>
BOT_STARTUP_DELAY_SECONDS=5
PYTHONUNBUFFERED=1
AI_ENABLED=false
AI_API_KEY=<секрет Taynik, требуется только при AI_ENABLED=true>
AI_BASE_URL=https://taynik.store/v1
AI_MODEL=gpt-6-luna
AI_TIMEOUT_SECONDS=180
AI_MAX_FILE_BYTES=10000000
AI_MAX_IMAGE_DIMENSION=2200
AI_MAX_REQUESTS_PER_HOUR=3
AI_MAX_CONCURRENT_REQUESTS=2
```

Скопируйте `.env.example` в локальный `.env`, но не добавляйте `.env` в Git.
Для запуска из корня проекта:

```bash
python3 -m pip install -r requirements.txt
TELEGRAM_BOT_TOKEN=... python3 run_bot.py
```

Для закрытого режима дополнительно задайте
`ALLOWED_TELEGRAM_IDS=123456789,987654321`.

Для Amvera в репозитории подготовлен `amvera.yml`. Секреты нужно добавлять в
настройках проекта Amvera, а не в файлы репозитория.

## Изолированный тест распознавания плана

Тестовый клиент в `scripts/test_taynik_vision.py` пока не подключён к
Telegram-боту и расчётному ядру. Он отправляет обезличенный JPG/PNG в
OpenAI-compatible API, требует JSON по фиксированной схеме и отклоняет лишние
поля. Результат является только предложением для проверки сметчиком.

Ключ не передавайте в чат, не записывайте в команду и не сохраняйте в `.env`.
Безопасный локальный запуск из корня проекта выполняется одной командой. Скрипт
сам скроет ввод ключа, после чего попросит перетащить в Терминал обезличенный
JPG/PNG:

```bash
PYTHONPATH=src python3 scripts/test_taynik_vision.py
```

Необязательные настройки: `AI_BASE_URL` (по умолчанию
`https://taynik.store/v1`), `AI_MODEL` (по умолчанию `gpt-6-luna`),
`AI_TIMEOUT_SECONDS` (по умолчанию 180 секунд) и `AI_MAX_IMAGE_BYTES`.
Совместимость Taynik с передачей
изображения и `response_format` считается **непроверенной**, пока не выполнен
успешный запрос с реальным ключом.

После успешной проверки ключ следует добавить в Amvera как секрет
`AI_API_KEY`. Остальные настройки добавляются обычными переменными, а функция
остаётся выключенной через `AI_ENABLED=false` до подключения кнопки и проверки
ограничений.

## Распознавание плана в Telegram

При `AI_ENABLED=true` в публичном меню появляется кнопка
`📐 Распознать план дома`. Перед загрузкой бот показывает уведомление о передаче
изображения внешнему AI-сервису и требует обезличенный JPG/PNG. Изображение
проверяется, уменьшается в памяти до заданного размера и не сохраняется на диск.

Результат AI показывается отдельной карточкой и не запускает расчёт
автоматически. После подтверждения распознанные геометрические параметры
заполняют черновик, отсутствующие значения бот спрашивает вручную, а фундамент
и Excel рассчитывает прежнее детерминированное ядро.

Публичное демо ограничивает число распознаваний на пользователя в час и общую
параллельность. Эти лимиты хранятся в памяти процесса и сбрасываются при
перезапуске контейнера. Для мгновенного отключения платной функции установите
`AI_ENABLED=false` и перезапустите приложение.
