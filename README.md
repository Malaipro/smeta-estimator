# Smeta Estimator

Проект внутренней программы для предварительного расчёта стоимости строительства домов и выгрузки результата в Excel.

## Текущая стадия

Сейчас формируется методика первой версии и база знаний. Приложение ещё не реализовано.

Подтверждённые границы первой версии:

- пользователь — сметчик;
- результат — предварительная, а не детальная рабочая смета;
- один или два этажа;
- простая геометрия дома;
- кирпич и Porotherm;
- готовые комплектации и ручной выбор разделов;
- расчёт до предчистовой отделки;
- выгрузка в Excel;
- будущая возможность предзаполнения параметров по плану или изображению.
