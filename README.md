# Smeta Estimator

Проект внутренней программы для предварительного расчёта стоимости строительства домов и выгрузки результата в Excel.

## Текущая стадия

Реализованы расчётное ядро свайно-ростверкового фундамента и закрытый
Telegram-демо-бот. Бот принимает параметры от сметчика, рассчитывает объёмы и
возвращает Excel. Стоимость пока не подставляется: база цен ещё не подключена.

Подтверждённые границы первой версии:

- пользователь — сметчик;
- результат — предварительная, а не детальная рабочая смета;
- один или два этажа;
- простая геометрия дома;
- кирпич и Porotherm;
- готовые комплектации и ручной выбор разделов;
- расчёт до предчистовой отделки;
- выгрузка в Excel;
- будущая возможность предзаполнения параметров по плану или изображению.

## Расчётное ядро фундамента

Первая программная часть проекта находится в `src/smeta_estimator/foundation`.
Она рассчитывает геометрию свайно-ростверкового фундамента и формирует строки
предварительной сметы без Telegram, сервера и внешней базы данных.

Запуск тестов:

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## Telegram-демо

Бот поддерживает команды `/start`, `/new`, `/cancel` и `/help`. Доступ закрыт
списком Telegram ID. История расчётов и исходные сообщения не сохраняются.

Переменные окружения:

```text
TELEGRAM_BOT_TOKEN=<токен BotFather>
ALLOWED_TELEGRAM_IDS=<один или несколько Telegram ID через запятую>
BOT_STARTUP_DELAY_SECONDS=5
PYTHONUNBUFFERED=1
```

Скопируйте `.env.example` в локальный `.env`, но не добавляйте `.env` в Git.
Для запуска из корня проекта:

```bash
python3 -m pip install -r requirements.txt
TELEGRAM_BOT_TOKEN=... ALLOWED_TELEGRAM_IDS=... python3 run_bot.py
```

Для Amvera в репозитории подготовлен `amvera.yml`. Секреты нужно добавлять в
настройках проекта Amvera, а не в файлы репозитория.
