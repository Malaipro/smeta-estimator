# Отчёт о проверке Telegram-демо фундамента

Дата: 2026-11-02  
Ветка: `codex/telegram-foundation-demo`  
Статус: локальная реализация готова; развертывание в Amvera ещё не выполнено.

## Реализовано

- Закрытый Telegram-бот с командами `/start`, `/new`, `/cancel`, `/help`.
- Доступ только для Telegram ID из `ALLOWED_TELEGRAM_IDS`.
- Пошаговый ввод названия объекта, наружного периметра и длины внутренних несущих стен.
- Показ тестовых параметров фундамента перед расчётом.
- Возможность последовательно изменить параметры или оставить значения по умолчанию.
- Расчёт через существующее ядро свайно-ростверкового фундамента.
- Excel с листами `Сводка`, `Исходные данные`, `Смета`.
- Отправка Excel в Telegram без сохранения истории расчётов на сервере.
- Конфигурация для Amvera и задержка 5 секунд перед long polling.

## Безопасность

- Токен Telegram и список ID читаются только из переменных окружения.
- При пустом списке ID бот не запускается.
- `.env` исключён из Git; добавлен только пустой `.env.example`.
- Логи HTTP-клиента отключены на уровне `INFO`, чтобы URL с токеном не попадал в журнал.
- Пользователю предлагается вводить условное название без адреса и ФИО.

## Проверки

- `27` модульных тестов: успешно.
- Компиляция Python-модулей: успешно.
- Excel повторно открыт через `openpyxl`: успешно.
- Все три листа визуально отрисованы и проверены.
- Формулы ручной корректировки и стоимости пересчитаны в независимом движке.
- Ошибки `#REF!`, `#DIV/0!`, `#VALUE!`, `#NAME?`, `#N/A`, `#NUM!`, `#NULL!`, `#SPILL!`, `#CALC!`: не найдены.

## Ограничения

- Стоимость не рассчитывается до подключения базы цен и ручных количеств.
- Telegram API не проверялся без реального токена.
- Amvera не проверялась до создания проекта и добавления секретов пользователем.
- Распознавание плана или фотографии вынесено в отдельный следующий блок.
