# Выгрузка предварительной сметы в Excel

## CONFIRMED: общий принцип

Excel формируется только по выбранным разделам. Документ должен явно показывать включённые и исключённые работы.

## Лист 1. Предварительная смета

- Объект.
- Дата расчёта.
- Регион.
- Основные параметры дома.
- Выбранная комплектация.
- Стоимость по разделам.
- Общий ориентир.
- Диапазон бюджета после калибровки методики.
- Перечень исключённых разделов.
- Срок актуальности расчёта.

## Лист 2. Расчёт

- Раздел.
- Основа расчёта.
- Единица измерения.
- Объём.
- Ставка.
- Коэффициенты.
- Стоимость.
- Источник объёма.
- Ручная корректировка.

## Лист 3. Допущения

- Принятые конструктивные решения.
- Параметры, заданные по умолчанию.
- Параметры, требующие уточнения.
- Что включено.
- Что не включено.
- Ограничения предварительного расчёта.

## Варианты представления

PLANNED:

- Полная внутренняя версия со ставками и коэффициентами.
- Клиентская версия по укрупнённым разделам.
- Ведомость объёмов без раскрытия части внутренних ставок.

## Проверки перед выгрузкой

- Все выбранные разделы рассчитаны.
- Невыбранные разделы не попали в итог.
- Стоимость разделов сходится с общим итогом.
- Ручные корректировки видимы.
- Неуточнённые параметры перечислены.
- Формулы Excel не содержат внешних ссылок и ошибок.
