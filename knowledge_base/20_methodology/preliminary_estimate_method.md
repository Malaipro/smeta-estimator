# Методика предварительной сметы

## Назначение

Предварительная смета даёт ориентир бюджета на ранней стадии общения с клиентом. Она не заменяет детальную смету по рабочей документации.

## Расчётный поток

1. Сметчик вводит параметры объекта.
2. Выбирает готовую комплектацию или свой набор разделов.
3. Программа рассчитывает геометрические показатели.
4. Для каждого выбранного раздела рассчитываются укрупнённые объёмы.
5. К объёмам применяются ставки и коэффициенты.
6. Сметчик проверяет и при необходимости корректирует результат.
7. Формируются общий ориентир, диапазон и Excel.

## Базовая формула раздела

```text
Объём × укрупнённая ставка × применимые коэффициенты = стоимость раздела
```

Пример для стены:

```text
Площадь наружных стен = периметр × высота − площадь проёмов
Стоимость стены = площадь стены × ставка выбранной конструкции
```

## Уровни параметров

Каждый раздел должен поддерживать:

1. Базовые обязательные параметры.
2. Дополнительные уточняющие параметры.
3. Ручную корректировку сметчика.

Дополнительные параметры можно добавлять позже без изменения структуры всей сметы.

## Источники количества

Для каждого рассчитанного объёма нужно хранить источник:

- Рассчитано по формуле.
- Введено вручную.
- Получено из проекта.
- Получено из спецификации.
- Предложено распознаванием и подтверждено сметчиком.

## Диапазон стоимости

До калибровки система не должна обещать фиксированную точность. Диапазон рассчитывается только после подтверждения методики на завершённых проектах.

PLANNED:

- Базовый ориентир.
- Нижняя и верхняя граница.
- Собственный уровень неопределённости для каждого раздела.
- Отдельная пометка параметров, требующих уточнения.

## Ограничения

- Программа не выбирает конструктив фундамента.
- Программа не подтверждает несущую способность.
- Распознанные данные требуют проверки сметчиком.
- Невключённые разделы должны быть явно перечислены в результате.
