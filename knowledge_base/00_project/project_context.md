# Контекст проекта

## CONFIRMED: цель

Создать внутреннюю программу для сметчика, которая по параметрам дома формирует предварительную смету строительства и выгружает результат в Excel.

## CONFIRMED: пользователь программы

Основной пользователь — сметчик. Клиент не заполняет расчётную форму самостоятельно. Сметчик получает данные клиента, вводит или подтверждает параметры, проверяет результат и формирует документ.

## CONFIRMED: стадия расчёта

Смета используется на ранней стадии запроса клиента. Она должна давать ориентир бюджета, а не претендовать на точность детальной рабочей сметы.

## CONFIRMED: граница результата

Расчёт охватывает дом до предчистовой отделки. Чистовая отделка, мебель, бытовая техника и декоративное оснащение не входят в базовую комплектацию.

## CONFIRMED: типы домов первой версии

- Один или два этажа.
- Простая геометрия из прямоугольных блоков.
- Кирпичные конструкции.
- Керамические блоки Porotherm.
- Возможность учитывать гараж, навес, террасу и другие простые дополнительные блоки.

## CONFIRMED: способ работы

При создании сметы сметчик выбирает готовую комплектацию или вручную включает нужные разделы. Программа показывает параметры только выбранных разделов. Перед экспортом объёмы, ставки и итоговые суммы можно скорректировать вручную.

## PLANNED: развитие

- Наполнение базы материалов, работ, механизмов и расценок.
- Детализация разделов через дополнительные параметры.
- Сохранение собственных шаблонов сметчика.
- Предзаполнение параметров по плану, чертежу или эскизу.
- Более детальные сметы по проектным спецификациям.

## IMPLEMENTED_IN_BRANCH: демо фундамента

В ветке `codex/demo-price-catalog` реализованы Python-ядро, закрытый Telegram-бот и
Excel-экспорт первого модуля:

- геометрия наружного и внутреннего ростверка;
- предварительное количество буронабивных свай;
- объём свай и бетона;
- раздельные коэффициенты запаса;
- округление бетона вверх;
- ручная замена количества свай с обязательной причиной;
- каталог из 28 позиций материалов, техники и работ;
- неполные цены и количества не превращаются в нулевой итог;
- временный каталог непроверенных демо-цен с происхождением каждой ставки;
- частичный итог только по строкам с известными объёмами и ценами;
- Excel из четырёх листов, включая отдельный лист источников цен;
- автоматические проверки контрольного сценария и граничных значений.

Это реализация в отдельной ветке, а не подтверждённый релиз. Актуальная база цен,
цоколь и остальные разделы дома пока не реализованы.
