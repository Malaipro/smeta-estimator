# Подтверждённые решения

Обновлено: 2026-11-04.

## Статус демо

- **APPROVED_FOR_DEMO:** 2026-11-04 пользователь утвердил текущую схему расчёта фундамента, частичного итога и Excel-выгрузки для демонстрационной версии.
- **LIMITATION:** утверждение для демо не подтверждает рыночную актуальность цен, полноту сметы или инженерную пригодность фундамента.

## Продукт

- **CONFIRMED:** программа предназначена для сметчика, а не для прямого использования клиентом.
- **CONFIRMED:** основной результат — предварительная смета на ранней стадии запроса.
- **CONFIRMED:** результат выгружается в Excel.
- **CONFIRMED:** база расценок будет наполняться и уточняться позже.
- **CONFIRMED:** в первом демо можно использовать цены из таблиц `алгоритмы(1).xlsx`, `арматура.xlsx` и `Бетон.xlsx` для проверки схемы расчёта и Excel-выгрузки.
- **CONFIRMED:** цены первого демо помечаются как тестовые и непроверенные; они не являются подтверждёнными ценами РТ или нормативной базой.
- **CONFIRMED:** после проверки демо тестовые цены и формулы будут корректироваться, а источники цен — заменяться на легитимные.
- **CONFIRMED:** первая версия должна считать дом целиком по укрупнённым разделам.
- **CONFIRMED:** базовая граница расчёта — предчистовая отделка.
- **CONFIRMED:** разработка начинается с отдельного законченного модуля фундамента и цоколя.
- **CONFIRMED:** первая демонстрационная версия должна быть доступна через Telegram.
- **CONFIRMED:** первое демо — обычный Telegram-бот с пошаговыми вопросами, не Mini App.
- **SUPERSEDED 2026-11-05:** первоначальное ограничение по Telegram ID заменено
  подтверждённым публичным режимом демо; при необходимости список ID можно
  снова включить переменной окружения.
- **CONFIRMED:** расчёты первого демо не сохраняются на сервере; Excel отправляется в чат.
- **CONFIRMED:** после проверки демо требуется оценка трудозатрат в часах на реализацию полной сметы дома.

## Объекты

- **CONFIRMED:** поддерживаются одноэтажные и двухэтажные дома.
- **CONFIRMED:** первая версия ограничивается простой геометрией.
- **CONFIRMED:** основные стеновые материалы — кирпич и Porotherm.
- **CONFIRMED:** детали конструкций будут добавляться позже как дополнительные параметры.

## Интерфейс расчёта

- **CONFIRMED:** на старте сметчик выбирает нужные разделы.
- **CONFIRMED:** должны быть готовые комплектации разделов.
- **CONFIRMED:** выбранную комплектацию можно корректировать.
- **CONFIRMED:** невключённые разделы не попадают в расчёт и экспорт.
- **CONFIRMED:** программа должна явно показывать, что включено и не включено.

## Планы и изображения

- **PLANNED:** дополнительная функция расчёта по плану, макету, чертежу или фотографии.
- **PLANNED:** распознавание не создаёт окончательную смету напрямую, а предлагает параметры для проверки сметчиком.
- **CONFIRMED 2026-11-05:** в Telegram-боте планируется отдельная кнопка
  `📐 Распознать план дома`; ручной ввод остаётся доступным.
- **APPROVED_FOR_COMPATIBILITY_TEST 2026-11-05:** до интеграции с ботом
  выполняется изолированный тест OpenAI-compatible API Taynik с моделью
  `gpt-6-luna` на обезличенном JPG/PNG.
- **CONFIRMED 2026-11-05:** после успешного теста API-ключ хранится в Amvera
  только как секрет `AI_API_KEY`; функция включается отдельно после проверки.
- **VERIFIED 2026-11-05:** Taynik принял JPG для доступной ключу модели
  `gpt-6-luna` и вернул валидный структурированный JSON. На фотографии дома без
  размеров модель не стала придумывать измерения. Точность чтения планов ещё не
  проверена.
- **CONFIRMED 2026-11-05:** тест распознавания ИИ остаётся публичным, как и
  обычный расчёт; отдельный список разрешённых Telegram ID не используется.
- **CONFIRMED 2026-11-05:** публичное распознавание защищается почасовым лимитом
  на пользователя, ограничением параллельных запросов и аварийным выключателем
  `AI_ENABLED`.
- **IMPLEMENTED_CODE 2026-11-05:** добавлены кнопка загрузки плана,
  уведомление о внешнем AI-сервисе, обработка JPG/PNG в памяти, карточка
  подтверждения, предзаполнение анкеты и продолжение ручных вопросов. До
  отдельного подтверждённого развёртывания `AI_ENABLED=false` скрывает кнопку.
